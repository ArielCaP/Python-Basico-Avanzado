# Calculadora con Funciones 🔢⚙️

Versión mejorada de mi primera calculadora, reorganizada usando funciones para cada operación matemática.

## 🎯 ¿Qué hace?

Lo mismo que la calculadora básica (suma, resta, multiplicación, división con manejo de división entre cero), pero ahora cada operación es una función independiente y reutilizable.

## 🔄 ¿Qué cambió respecto a la Calculadora básica?

| Antes (v1) | Ahora (v2) |
|---|---|
| Todo el cálculo estaba directo dentro del `if/elif` | Cada operación es su propia función (`sumar`, `restar`, `multiplicar`, `dividir`) |
| Código repetido si se necesitaba en otro lugar | Las funciones se pueden reutilizar en cualquier otro programa |

## 📚 Lo que aprendí

- `def` para definir funciones
- Parámetros como "cajones" que reciben datos
- `return` para devolver un resultado
- Cómo llamar una función y guardar lo que devuelve
- Por qué dividir el código en funciones facilita reutilizarlo y mantenerlo
