# Lista de Tareas (To-Do List) 📝

Programa de consola que permite gestionar una lista de tareas: agregarlas, verlas, marcarlas como completadas y eliminarlas, mediante un menú interactivo.

## 🎯 ¿Qué hace?

1. Muestra un menú con 5 opciones: agregar, ver, completar, eliminar tareas, o salir
2. Cada tarea se guarda con su descripción y su estado (completada o no)
3. El menú se repite hasta que el usuario decide salir

## 📚 Lo que aprendí

- **Diccionarios** (`{"clave": valor}`) para agrupar varios datos relacionados en un mismo elemento
- **Listas de diccionarios** para manejar varios elementos con múltiples datos cada uno
- Funciones que **reciben y modifican** una lista, no solo devuelven un resultado
- Diferencia entre el índice que ve el usuario (empieza en 1) y el índice real de Python (empieza en 0)
- `.pop(indice)` para eliminar elementos de una lista
- Reutilizar una función dentro de otra función (`completar_tarea` usa `ver_tareas`)
- Validar que un número ingresado exista antes de usarlo, evitando errores
- Operador ternario (`"✅" if condicion else "❌"`) para condicionales en una sola línea
